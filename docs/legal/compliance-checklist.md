# 商业化合规清单（可执行版本）

本清单用于把“隐私/合规”从口号变为可交付物。并非法律意见，建议商业化前由律师/合规顾问审阅。

## 1. 法域与适用性（先确定边界）
- 服务对象所在地：国内/海外/同时
- 运营主体：公司主体/个人/海外主体
- 是否面向未成年人
- 是否引入第三方处理：分析、OCR、账单导入、客服、邮件系统等

## 2. 最小合规文档（上线必备）
- 隐私政策（Privacy Policy）
- 服务条款（Terms of Service）
- Cookie/追踪声明（若有分析/广告/第三方脚本）
- 未成年人政策（若涉及 child / 未成年人）
- 安全与事件响应说明（对外公开的简版）

## 3. 产品能力必须与声明一致（上线前验收）
- 数据导出（个人/家庭维度）
- 数据删除与账号注销（明确软/硬删除、保留期、可恢复窗口）
- 权限与可见范围（家庭共享/私密/受限）
- 邀请机制安全：撤销、过期、绑定邮箱（可选）
- 访问控制：最小字段展示、敏感信息不在日志出现

## 4. 记录与内部制度（商业化后强烈建议）
- 数据处理活动记录（RoPA）
- 第三方处理清单与合同（DPA/处理协议）
- 安全审计与渗透测试报告（周期化）
- 备份与恢复演练
- 安全事件响应预案（SOP）与演练

## 5. 技术底座建议（按优先级）
### P0（现在就该做）
- 数据最小化：字段/页面/日志层面都遵循
- 默认隐私：高敏域默认私密或更小共享
- RLS 全表开启 + 关键 RPC security definer 审核

### P1（商业化前）
- 字段级加密（对极敏字段）
- 审计日志（邀请/导出/删除/权限变更）
- 速率限制与反滥用（邀请/登录/导出）

### P2（规模化后）
- 多租户合规隔离（企业/家庭）
- 安全告警与可观测性体系
