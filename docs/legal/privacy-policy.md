# 隐私政策

## 1. 引言

Family Inc. OS 致力于保护用户隐私和个人数据。本隐私政策说明了我们如何收集、使用、存储和保护您的个人信息，以及您对这些信息的权利。

## 2. 数据分级与收集

### 2.1 数据分级

我们将数据分为三个等级：

- **P0（高敏/高风险）**：
  - 财务数据：交易金额、交易时间、分类、描述
  - 健康数据：体检、用药、病史、心理相关信息
  - 关系数据：家庭矛盾、沟通记录、事件日志
  - 未成年人相关：child 角色产生的任何可识别信息

- **P1（敏感/可识别）**：
  - 账号信息：邮箱、用户 ID（UUID）、姓名/昵称
  - 家庭信息：家庭名称、家庭成员列表、角色
  - 邀请信息：邀请 token、邀请绑定邮箱

- **P2（低敏/运营）**：
  - 偏好与配置：主题、语言、显示偏好
  - 统计与诊断：仅聚合后的使用行为

### 2.2 数据收集方式

- **用户主动提供**：当您注册、创建家庭、添加交易、填写个人资料等时，您主动提供的信息
- **自动收集**：我们可能自动收集使用信息，如登录时间、设备信息等
- **第三方服务**：通过 Supabase 等第三方服务收集的认证信息

## 3. 数据使用目的

### 3.1 核心功能

- **认证与账号管理**：登录鉴权、会话管理、账户安全
- **家庭管理**：家庭成员协作、权限控制、邀请管理
- **财务管理**：记账、统计、预算与洞察
- **健康管理**：健康档案管理、健康指标追踪、保险管理
- **关系管理**：家庭关系管理、事件记录、外部联系人管理
- **AI辅助**：智能分析、决策支持、个性化建议

### 3.2 其他用途

- **安全保障**：保护用户账户安全、防止欺诈和滥用
- **产品改进**：基于用户反馈和使用数据改进产品功能
- **合规要求**：满足法律法规和监管要求

## 4. 数据存储与保护

### 4.1 存储位置

- **Supabase Auth**：存储账号认证信息
- **Supabase Postgres**：存储业务数据
- **前端本地存储**：存储会话信息和用户偏好

### 4.2 保护措施

- **数据加密**：传输和存储过程中的数据加密
- **访问控制**：基于角色的访问控制和 Row Level Security (RLS)
- **安全审计**：定期安全审计和漏洞扫描
- **数据备份**：定期数据备份和灾难恢复

### 4.3 私密数据保护

- **私密交易**：支持设置交易为仅本人可见
- **最小化数据收集**：交易描述为可选字段，减少敏感信息收集
- **端到端加密**：敏感字段的端到端加密

## 5. 数据共享与披露

### 5.1 内部使用

- 仅授权人员可以访问必要的数据，且必须遵循严格的保密义务

### 5.2 第三方服务

- **Supabase**：用于认证和数据存储
- **OpenAI**：用于AI辅助功能
- 其他第三方服务仅在获得用户明确同意后使用

### 5.3 法律要求

- 当法律要求或政府机构要求时，我们可能会披露必要的数据
- 为保护用户权利、财产或安全，我们可能会披露必要的数据

## 6. 用户权利

### 6.1 数据访问

- 您有权访问您的个人数据和家庭数据
- 您可以在产品中查看您的账户信息和交易记录

### 6.2 数据导出

- 您有权导出您的个人数据和家庭数据
- 导出格式包括 CSV、JSON 等常见格式

### 6.3 数据删除

- 您有权删除您的个人数据
- 账户注销后，我们会按照数据保留政策处理您的数据

### 6.4 隐私设置

- 您可以设置默认的交易可见性（家庭可见/仅本人可见）
- 您可以控制是否在家庭中显示真实姓名

## 7. 数据保留期

- **账号与家庭**：用户存续期间保留；注销后进入删除流程
- **邀请**：过期/撤销后保留 30~180 天用于审计与反滥用
- **交易**：默认长期保留；用户可主动删除
- **日志**：仅记录必要的安全事件与错误码，保留 7~30 天

- 我们可能会不时更新本隐私政策
- 重要更新会通过电子邮件或产品通知告知用户
- 继续使用产品表示您同意更新后的隐私政策
