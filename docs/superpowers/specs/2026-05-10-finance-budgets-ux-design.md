# 预算管理页（/finance/budgets）体验重构 - 设计稿

**目标**：把预算管理页的主任务聚焦为“当月预算配置”，同时保留“复盘（月/季/年）”与“模板管理”，但降低同屏混杂带来的认知负担与误操作风险。

## 现状诊断

### 主要问题（用户体感“混乱”的根因）
- 同屏承载 4 类任务：当月配置（可写）/ 复盘（月季年，只读）/ 模板资产（跨月）/ 教学与建议（指导），用户需要同时理解多个时间维度与口径。
- 移动端首屏被汇总卡片占据，主操作（新增/编辑/补齐/补全未预算）不在第一屏，操作路径偏长。
- “月/季/年”切换与“本月预算（可编辑）”同屏存在，容易被误解为切换后编辑对象也变了。
- 写操作入口过多且不一致：部分路径直接写入（模板“用到本月”），缺少预览/确认，增加误操作。

## 设计决策（背景 → 约束 → 方案 → 取舍 → 风险 → 建议）

### 1) 信息架构：同页分 Tab（默认进“配置”）

**背景**
- 现状同屏混杂导致主任务不清晰，且“复盘视角”与“可编辑对象”分离不明显。

**约束**
- 维持 `/finance/budgets` 路由不变；不拆新页面。
- 不削功能：配置/复盘/模板都保留。

**方案（采用）**
- `/finance/budgets` 增加 3 个 Tab：**配置（默认）｜复盘｜模板**
- 规则：复盘 Tab **只读**，不出现编辑/删除/写入入口。

**取舍**
- 优：强分区降低认知负担；避免“切到季度还在改当月”的误解。
- 缺：需要拆分现有页面块到 Tab（结构改动较大但收益高）。

**风险**
- 之前依赖同屏快速访问模板/复盘的用户，发现性下降。

**建议**
- 配置 Tab 首屏提供明确入口到复盘/模板（Tab 本身 + 复盘 CTA）。

### 2) 主任务聚焦：配置 Tab 只呈现当月配置必需信息

**背景**
- 预算配置的核心是“设上限 + 快速补齐缺口”，而不是同屏看大量解释与重复指标。

**约束**
- 保留关键洞察：未预算分类/支出缺口提示必须一眼可见。

**方案（采用）**
- 配置 Tab 顶部控制：月份切换 + 主按钮「补齐本月」+ 次按钮「新增预算」
- KPI 收敛为 3 项（均为当月口径）：**预算合计、已花费、未预算支出**
- 若未预算支出 > 0：显示提示条（含 Top 未预算分类快捷入口，点击进入新增预算弹窗并预填分类/建议金额）
- 本月预算列表聚焦编辑：分类/金额/已花费/剩余/进度；来源（模板/继承）弱化为次级信息

**取舍**
- 优：首屏更“能做事”；减少概念与口径碎片化。
- 缺：覆盖率/执行率展示会更弱（但可在复盘 Tab 体现）。

**风险**
- 依赖覆盖率判断的用户可能觉得信息少。

**建议**
- 在复盘 Tab 提供完整指标与趋势；配置 Tab 保持“行动导向”。

### 3) “补齐本月”：改为手动触发（避免浏览即写库）

**背景**
- 自动补齐意味着“打开页面/切月份=写数据库”，不可预期且错误被吞会让用户更困惑。

**约束**
- 仍需保留补齐能力与 toast 反馈。

**方案（采用）**
- 默认不自动调用补齐 RPC；仅在用户点击「补齐本月」时触发。
- 结果反馈明确：新增了多少条、来自模板/继承各多少（让因果链可见）。

**取舍**
- 优：可预期、可解释、可回忆。
- 缺：新月份可能初始为空（需要 UI 引导）。

**风险**
- 用户不点补齐就看到空列表，误以为坏了。

**建议**
- 空态文案明确引导：先补齐/新增；并提示“建议先把固定项存模板”。

### 4) 模板“用到本月”：增加预览/确认（默认仅新增缺失）

**背景**
- 现状“用到本月”直接写入且路径不经过编辑弹窗，误操作成本高。

**约束**
- 交互要轻量；不做复杂的逐条编辑。

**方案（采用）**
- 点击“用到本月”先打开预览弹窗（不写入）
- 弹窗显示：
  - 目标月份（明确范围）
  - 将新增 X 项（本月缺失）
  - 将覆盖 Y 项（默认 0）
  - 开关：覆盖已有（默认关闭）
  - 确认应用/取消
- 默认策略：**仅新增缺失**（不覆盖已有），覆盖为可选开关。

**取舍**
- 优：误操作显著下降；用户知道自己将改变什么。
- 缺：多一步确认。

**风险**
- 用户期待“一键生效”，觉得慢。

**建议**
- 弹窗做轻量清单 + 结果摘要，确认一步完成。

## 验收标准（面向用户体验）
- 默认进入配置 Tab，移动端首屏能看到：月份、补齐/新增、3 个 KPI、未预算提示（若有）。
- 切换到复盘 Tab 后，页面上无任何会写入数据的按钮/入口。
- 点击模板“用到本月”不会立刻改变数据，必须在预览弹窗确认。
- “补齐本月”不会在打开页面/切换月份时自动触发；仅点击按钮触发。
