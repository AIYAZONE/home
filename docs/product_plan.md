# Family Inc. OS 产品规划（MVP → 可扩展）

## 定位与愿景
- 定位：家庭协同管理的经营系统（把长期目标拆解成计划与执行）
- 价值主张：减少摩擦、提高透明度、形成可复盘的家庭决策与执行闭环

## 目标用户与角色
### 角色
- Admin：创建家庭、邀请成员、权限配置、查看全局数据与报告
- Parent：协同录入/查看家庭数据、参与计划与任务
- Child：受限可见、参与任务与成长目标
- 访客/匿名：仅可通过邀请 token 获取最小化信息

### 核心 JTBD
- 管理员：我想快速看到“家庭现在状况”，并推动成员一起执行计划
- 成员：我想知道我该做什么、能看什么，并能轻松贡献数据与进度

## 产品模块（信息架构 IA）
### 全局导航（一级）
- Dashboard（概览）
- Finance（财务）
- Growth（成长）
- Health（健康）
- Relationships（关系）
- Advisor（AI 顾问）
- Settings（设置）

### 页面与关键任务（按优先级）
#### P0：Onboarding
- 登录/注册
- 创建家庭
- 通过邀请加入家庭

#### P0：Finance
- 交易录入（快速、低摩擦）
- 交易列表（筛选、搜索、编辑）
- 基础统计（收支、余额、趋势）

#### P0：Settings / Family
- 成员列表
- 邀请链接创建与管理（查看/撤销）
- 个人资料（姓名、主题）

#### P1：Dashboard
- 关键指标卡片（可配置）
- 最近活动（交易/任务/提醒）
- 待办事项（引导到具体模块）

#### P2：增长/健康/关系/AI
- 先提供高质量结构与导航，再逐域补齐闭环功能

## 关键用户路径（端到端）
### 路径 A：新建家庭
1. 用户注册/登录
2. 创建家庭（成为 Admin）
3. 进入 Dashboard
4. 进入 Finance 录入第一笔交易
5. 去 Settings 生成邀请链接

### 路径 B：邀请加入
1. 访客打开 join 链接（token）
2. 登录/注册
3. 点击“确认加入”
4. 回到 Dashboard，看到家庭数据

### 路径 C：日常记账
1. Finance → 快速录入
2. 列表中查看/筛选
3. Dashboard 看趋势与建议

## MVP 边界与质量门槛
- MVP 必须稳定：创建/加入家庭、邀请、交易 CRUD、基础概览
- MVP 必须统一：全站同一套组件、间距、状态反馈（loading/empty/error/toast）
- MVP 必须移动友好：320px 起无横向滚动、交互热区≥44px

## 里程碑式迭代（不含日期）
### Phase 0：地基与一致性
- AppShell（桌面 + 移动导航）
- UI 设计系统（tokens + 组件库）
- Onboarding 体验升级

### Phase 1：核心闭环（可日常使用）
- 家庭创建/邀请/加入稳定（写入 RPC 化）
- 交易录入与列表体验完善
- Dashboard 基础可用

### Phase 2：决策支持
- 趋势/预算/提醒
- 更好的报表与洞察

### Phase 3：多域扩展 + AI
- Growth/Health/Relationships 逐域闭环
- AI 从问答升级为“可执行建议 + 一键落地任务/计划”
